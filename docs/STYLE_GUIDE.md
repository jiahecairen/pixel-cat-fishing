# 像素美术规范

所有素材由 `tools/art/generate.py` 用代码逐像素生成，不手工修图。改图 = 改脚本后重新运行：

```bash
python3 tools/art/generate.py
```

脚本会自动检查每张图只用了调色板里的颜色，并导出 `presentation/palette.gd` 供代码绘制（鱼竿、鱼线、数字）使用同一套颜色。

## 规则

| 项目 | 规定 |
|---|---|
| 调色板 | `tools/art/palette.py` 中的 24 色，禁止使用其它颜色 |
| 画布 | 整个场景 128×96 美术像素（能装进 3DS 上屏 400×240） |
| 放大 | 只允许整数倍，最近邻过滤，不做任何平滑 |
| 描边 | 所有角色/物件 1 像素深色描边（色 `K`）；UI 文字和特效（闪光、水花）不描边 |
| 光源 | 左上方：亮部在左上，暗部在右下 |
| 尺寸 | 猫 32×32，船 64×22，鱼 18×12，图标约 9–11，按钮 11×11，数字 3×5 |
| 动画 | 位移以整像素为单位，不做亚像素移动、旋转或缩放 |
| 文字 | 数字用自绘 3×5 字体；中文用 Fusion Pixel 10px 预渲染的标签图集，不在运行时用字体引擎渲染 |
| 线条 | 代码画线一律用逐像素 Bresenham（`_pixel_line`），不用抗锯齿线 |

## 为将来的"自定义形象"预留

猫的毛色只使用三个调色板槽位：`f`（基础）、`F`（暗部）、`l`（亮部），帽子是独立的一段绘制代码（`cat(hat=...)`）。
将来做开局捏猫时：毛色 = 换这三个槽位的颜色；帽子/花纹/配饰 = 拆成独立图层叠加。
