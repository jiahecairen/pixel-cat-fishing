# CatFishing — 桌面小猫钓鱼 × 番茄钟

macOS 桌面上的像素小猫，在透明悬浮窗里坐船钓鱼。开始一个番茄钟，小猫就陪你专注 25 分钟，完成后把渔获加成结算成金币。

## 运行

**直接玩**：双击 `build/CatFishing.app`（未经 Apple 公证；如果系统拦截，在"系统设置 → 隐私与安全性"里点"仍要打开"，或右键 → 打开）。

**开发调试**：用 Godot 4.7 打开本文件夹（`project.godot`），按 F5。或在终端：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path /Users/rain/DevGame/CC_CatFashing
```

## 两种视图

游戏是一个横版世界：海上钓点 → 码头 → 小镇街道 → 摊位。同一个世界有两种看法，点面板右上角的方框按钮切换：

| 视图 | 说明 |
|---|---|
| 全画面 | 普通窗口，可随意拉伸，能看到天空、远山和整条街。可以用方向键亲自带小猫在镇上走。默认视图 |
| 迷你悬浮窗 | 桌面上的透明小窗，置顶，只取小猫周围一小块；面板和场景以外的透明区域不拦截鼠标；拖动场景可以移动窗口，位置会被记住 |

面板按钮：

- 第一排：开始番茄（专注中变为"放弃"，休息中变为"跳过休息"）、去小镇、设置（齿轮）、切换视图
- 第二排：背包（物品栏）、×（退出游戏，会先问"确定要退出吗"）。任何面板打开时这个按钮会隐藏，面板右上角有它自己的关闭按钮

商店、图鉴、统计、换形象在面板上没有按钮，要走进镇上对应的房子才能打开（见下面"小镇里的房子"）。

第一次启动会先弹出捏猫面板，选好点"完成"。

### 全画面里的操作

| 按键 | 作用 |
|---|---|
| ← → 或 A D | 在小镇里走动（小猫在镇上时随时可以接管，包括正在摆摊时） |
| 空格 / 回车 / E / ↑ | 互动：在海上 = 出发去小镇；走到摊位旁 = 开张摆摊；走到码头 = 上船返航（鱼没卖完也可以走）；走到门口 = 进屋；走到居民旁 = 聊天 |
| Esc | 关闭面板（从店里出来） |

- 镜头有"静止区"：小猫在画面中间 30%–70% 范围内活动时镜头不动，走出这个范围镜头才跟上，所以小猫不会走出画面；镜头也不会越过世界的左右边界。
- 一旦用方向键接管，小猫就一直听你的，不会自己走开，这期间不卖鱼。想让它继续干活：走到摊位旁按空格开张，或走到码头按空格上船；切到迷你悬浮窗也会交还给自动流程。
- 迷你悬浮窗里没有键盘操作，小猫全程自动。

### 小镇里的房子

走到门口按空格进屋，屋里同样用方向键走动；走回门口按空格出门。

| 房子 | 屋里有什么 | 走到哪里按空格 |
|---|---|---|
| 小猫的家（红屋顶） | 书架、日历、床 | 书架 = 图鉴；日历 = 番茄统计 |
| 裁缝铺（蓝屋顶） | 兔子店主、帽子货架、镜子 | 镜子 = 换毛色、花纹、帽子 |
| 渔具店（绿屋顶） | 熊店主、渔具货架、柜台 | 柜台 = 鱼竿、鱼饵、鱼篓升级 |

- 在屋里时外面的时间照常走，但小猫不在摊位上，所以不卖鱼。
- 屋内位置不存档：关掉重开，小猫回到门口的街上。切到迷你悬浮窗也会回到街上。

## 玩法

小猫的一天是一个循环：

1. **钓鱼**：每 20–60 秒钓一条，鱼进鱼篓（10 格起，可升级）。
2. **鱼篓满**：小猫头上冒出气泡。点气泡（或面板上的小房子按钮）它就出发；鱼篓没满也可以点小房子提前去。
   - 不点的话，小猫在船上睡觉或玩掌机，每 3–5 分钟偷吃掉鱼篓里最便宜的一条（稀有鱼不吃），腾出空位后接着钓。
3. **航行**：划船去小镇，30 秒。
4. **摆摊**：背着鱼篓走到摊位，每 8–20 秒来一位顾客买走一条鱼。
5. **返航**：卖空后走回码头、划船回钓点，继续钓。

**宝箱**：每一竿有 4% 的概率钓上来的不是鱼而是宝箱。宝箱当场打开，金币直接入账，不占鱼篓也不进木箱。

| 档位 | 概率 | 金币 |
|---|---|---|
| 小 | 70% | 20–60 |
| 中 | 25% | 80–150 |
| 大 | 5% | 300–500 |

概率和金额在 `data/balance.json` 的 `chest` 段。累计钓到的宝箱数显示在图鉴页底部。

宝箱里除了金币，有 60% 的概率还带一件物品，进入物品栏。

## 物品栏

点面板第二排的背包按钮打开；全画面里也可以按 Tab 或 I。全画面里它占据画面的大部分，迷你悬浮窗里是缩小版。同种物品叠在一格里，没有容量上限。

| 物品 | 用法 | 效果 |
|---|---|---|
| 漂流瓶 | 使用 | 得 10–60 金币 |
| 幸运鱼饵 | 使用 | 10 分钟内稀有鱼更容易上钩、宝箱概率翻倍；连着用时间会接上；番茄休息的时间不算 |
| 招财铃 | 使用 | 接下来 5 单摆摊售价翻倍（可以和专注的 1.5 倍叠加） |
| 藏宝图碎片 | 集齐 4 片后使用 | 得 400–600 金币 |
| 珍珠 | 不能使用 | 收藏品 |
| 旧靴子 | 不能使用 | 收藏品 |

操作：鼠标点格子选中，点"使用"；全画面里也可以用方向键选、空格使用、Esc 关闭。幸运鱼饵和招财铃生效时，选中它们能看到剩余时间或剩余单数。

物品的定义、宝箱里的权重和效果数值都在 `data/balance.json` 的 `items` 段。

去不去小镇始终由你决定（点气泡、点小房子按钮或按空格），小猫不会自己出发。

番茄钟叠加在这个循环上：

| 状态 | 效果 |
|---|---|
| 专注中，小猫在海上 | 正常速度钓鱼，鱼进不限量的"木箱"（面板上显示木箱图标），不占鱼篓、不会满、不打断你 |
| 专注中，小猫在摆摊 | 每条鱼按 1.5 倍价格卖出 |
| 完成番茄 | 木箱里的鱼按 1.5 倍结算，另加 10 金币；每第 4 个番茄再加 50 |
| 休息（5 / 15 分钟） | 整个循环暂停，小猫原地打盹 |
| 自由挂机 | 钓鱼速度减半，鱼进鱼篓；满篓后要你点气泡才出发 |
| 放弃专注 | 木箱里的鱼按原价结算，没有完成奖励，不计入番茄数 |

## 菜单

| 标签 | 内容 |
|---|---|
| 商店 | 用金币升级，每项 5 级。鱼竿：自由挂机更快（满级时与专注同速，不会快于 20–60 秒）；鱼饵：稀有鱼更容易上钩；鱼篓：每级容量 +2 |
| 图鉴 | 每种鱼钓到的数量和单价，没钓到过的显示为剪影 |
| 统计 | 今日番茄数、累计番茄数、近七日柱状图 |
| 设置 | 专注 / 短休 / 长休时长（分钟）；迷你窗大小（2–5 倍）和音效音量（0 静音–3）点加号循环切换。时长改动从下一个阶段开始生效 |

数值全部在 `data/balance.json` 和 `data/fish.json`，改完重启即可。

## 小猫形象

6 种毛色 × 4 种花纹 × 4 种帽子，共 96 种组合，随时可以点面板上的小猫头像更换，不花金币。

- 毛色：橘、灰、黑、白、棕、金
- 花纹：纯色、白肚、虎斑、条纹
- 帽子：无帽、草帽、渔夫帽、贝雷帽

选项列表在 `data/cat.json`。加新毛色只需在里面加一行（颜色用调色板键）并重新运行素材脚本（生成名字标签）；加新帽子需要在 `tools/art/generate.py` 的 `draw_hat` 里画出来。

## 音效与动画

音效由 `tools/audio/generate.py` 用方波/三角波/噪声合成（8-bit 风格），共 11 个：抛竿、咬钩、收竿、上鱼、稀有鱼、金币、购买、失败、番茄完成、休息结束、按钮。

动画反馈：浮漂落水和咬钩时有水花；钓到鱼、卖出鱼时小猫会眯眼跳一下；钓到稀有鱼有闪光；完成番茄时满屏落星；划船时有桨和水花；顾客买完会拎着鱼走开。

## 导出

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --export-release "macOS" build/CatFishing.zip
```

需要先在 Godot 编辑器里安装导出模板（编辑器 → 管理导出模板）。导出预设在 `export_presets.cfg`：通用二进制（Intel + Apple Silicon）、临时签名、不公证。

## 目录结构

```
core/          纯逻辑，不依赖窗口和节点：状态、钓鱼状态机、活动循环（journey）、番茄钟、经济、升级
io/            配置加载与校验、原子存档
platform/      平台适配：窗口、穿透、拖动、通知。移植新平台只在这里加一个类
presentation/  画面与输入：main（视图与界面）、world（横版世界）、menu、wardrobe
data/          鱼种与数值配置
assets/sprites 生成出的像素素材
assets/cat     小猫的分层素材（毛色蒙版、花纹蒙版、固定层、帽子）
assets/sfx     生成出的音效
tools/art/     素材生成脚本与调色板
tools/audio/   音效生成脚本
build/         导出的 macOS 应用（不进版本库）
tests/         无界面单元测试
```


调试用的环境变量（仅调试版生效，导出的应用里无效）：

| 变量 | 作用 |
|---|---|
| `CATFISH_SPEED=60` | 时间快 60 倍（25 分钟变 25 秒） |
| `CATFISH_VIEW=0` / `1` | 强制迷你 / 全画面视图 |
| `CATFISH_FILL=10` | 开局往鱼篓里塞 10 条鱼 |
| `CATFISH_GO=1` | 开局直接出发去小镇 |
| `CATFISH_AUTOFOCUS=1` | 开局直接开始专注 |
| `CATFISH_LOOK=2,2,3` | 指定形象（毛色,花纹,帽子 的下标）并跳过捏猫 |
| `CATFISH_MENU=0..3` | 开局打开菜单的某个标签页 |
| `CATFISH_ROAM=1` / `-1` | 模拟一直按着右 / 左方向键（`CATFISH_ROAM_AT=帧号` 指定从哪一帧开始按） |
| `CATFISH_CHEST=1` | 每一竿都钓到宝箱 |
| `CATFISH_ITEMS=3` | 开局每种物品给 3 个，并打开物品栏 |
| `CATFISH_SEED=5` | 固定随机种子，让每次运行的时间点一致 |
| `CATFISH_BREAK=1` | 开局直接处于番茄休息中 |
| `CATFISH_CLICK=10:116,8` | 在第 10 帧模拟点击界面坐标 (116,8) |
| `CATFISH_ROOM=tackle` | 到镇上后直接进这间屋子（`tackle` / `tailor` / `home`） |
| `CATFISH_ACT_AT=200` | 在第 200 帧模拟按一次互动键 |
| `CATFISH_SHOT=/tmp/a:60,120` | 在第 60、120 帧截图到 `/tmp/a_60.png` 等，然后退出 |

## 第三方素材

界面中文标签用 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) 10px 预渲染成图集，字体以 SIL OFL 1.1 许可发布，许可文本在 `tools/art/fonts/OFL.txt`。新增文字时把它加到 `tools/art/generate.py` 的 `LABELS` 列表后重新生成。

## 移植说明

- **Windows**：`platform/desktop_adapter.gd` 已走通用 Godot API，预计只需实测和通知部分的小改。
- **iOS / Android**：自动落到基类适配器，只有全画面视图（没有迷你悬浮窗，切换按钮会隐藏）。需要补触屏布局和通知。
- **Switch**：需任天堂开发者资质与第三方 Godot 移植方案。
- **3DS**：Godot 4 无法运行，计划单独做一个精简版。可复用的是 `assets/`、`data/` 和规则设计；世界高度 180 像素，3DS 上屏（400×240）装得下。
